- [x] ~~**CP MQTT functional test hangs on TCP connect to host mosquitto**~~ — **fixed 2026-04-28** (this commit, after empirical diagnosis).  The hang was a red herring; the actual bug was a clock-domain mismatch in microseconds — and it was a **test-only bug**, not a library bug.  CircuitPython doesn't have `time.ticks_ms`, so the test's local `_ticks_ms()` helper fell back to `time.monotonic() * 1000` (unwrapped float-derived ms).  `chumicro-timing` on CP resolves to `supervisor.ticks_ms` (29-bit-wrapped per Decision 0008).  MQTT client computed deadlines via `chumicro_timing` but consumed the test's `now_ms` from the other domain.  `ticks_diff(wrapped_deadline, unwrapped_now_ms)` produced wrong-signed results and `_check_deadlines` fired CONNACK timeout on the very first tick, before any inbound recv even happened.

  Production code was never affected: `chumicro-runner.Runner` sources `now_ms` from `chumicro_timing.ticks_ms()` once per tick and passes that value to every registered service — every service sees identical `now_ms`, in the same domain as MQTT's internal deadlines.  The bug only surfaces when test code rolls its own ad-hoc poll loop with a non-`chumicro_timing` tick source.

  Fix: **test side only** — replace the local `_ticks_ms()` shim in `test_real_broker.py` with `chumicro_timing.ticks_ms`.  An earlier draft of this commit also "hardened" `MQTTClient.handle(now_ms)` to ignore the caller-supplied value, but that broke the Decision 0014 runner contract (every service in a tick must see the same `now_ms` for deterministic intra-tick ordering / fairness / composed deadlines).  Reverted; the library faithfully honors the runner-supplied `now_ms` and consumers must follow the contract.

  All four boards now pass `test_real_mqtt_publish_subscribe_round_trip` against the host-side mosquitto fixture: Pi Pico W MP 2.69 s, Pi Pico W CP (flash) 3.59 s, Lolin S2 MP 4.17 s, Lolin S2 CP 4.50 s.  Diagnosed by spawning mosquitto manually with verbose logging and comparing the broker's view of the connection (CONNACK sent, client closed immediately) with `_check_deadlines`-side instrumentation that revealed `state=failed` after a single tick.
