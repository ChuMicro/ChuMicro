ChuMicro

Cross-runtime Python libraries for CircuitPython, MicroPython, and CPython — built for ESP32, RP2040, and other microcontrollers.

CircuitPython MicroPython CPython

chumicro-timing

Wraparound-safe millisecond tick helpers, heartbeat scheduling, and deterministic test fakes. The foundation that other libraries build on.

Guide | API | Testing | Experimental

chumicro-runner

Tick-based task runner with check/handle gates, periodic tasks, and shared timestamps. No async required — deterministic scheduling for real-time embedded loops.

Guide | API | Testing | Experimental

chumicro-compat

Cross-runtime compatibility polyfills. Provides functools.partial for MicroPython and CircuitPython where it’s missing, with the same API as CPython.

Guide | API | Experimental

chumicro-msgpack

Compact MessagePack serialization with native CircuitPython C module delegation. Bytes and stream APIs for settings storage, IPC, and network payloads.

Guide | API | Experimental

Install

pip (CPython)

pip install chumicro-timing

circup (CircuitPython)

circup bundle-add ChuMicro/ChuMicro-Bundle
circup install chumicro-timing

mip (MicroPython)

mpremote mip install \
  github:ChuMicro/ChuMicro-Bundle/chumicro_timing

Release channels

ChannelBranchDescription
