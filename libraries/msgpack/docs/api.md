# API Reference

## `chumicro_msgpack`

`packb` and `unpackb` work on `bytes` in memory; `pack` and `unpack` read and write a stream, which keeps a large value off the heap on a small board.

::: chumicro_msgpack
    options:
      members:
        - packb
        - unpackb
        - pack
        - unpack
