# API Reference

## `chumicro_msgpack`

`chumicro_msgpack` exports `packb`, `unpackb`, `pack`, and `unpack`, and a program starts with [`packb`](#chumicro_msgpack.packb) and [`unpackb`](#chumicro_msgpack.unpackb).

::: chumicro_msgpack
    options:
      members:
        - packb
        - unpackb
        - pack
        - unpack
