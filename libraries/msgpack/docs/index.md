# chumicro-msgpack

Cross-runtime [MessagePack](https://msgpack.org) serialization for CircuitPython, MicroPython, and CPython.

Encodes Python objects to compact binary bytes and decodes them back.  On CircuitPython boards with the native `msgpack` C module, all functions delegate to the built-in.
