# Guides

Choose the result you need next, whether you want to run a board program, adapt one, understand how it works, or contribute a library. ChuMicro provides Python libraries for MicroPython and CircuitPython boards, laptop tools for setup, deployment, and inspection, and a way to test on the host with CPython.

These routes are independent. You do not need to finish a first project before exploring cooperative multitasking or contributing. Choosing a destination requires no hardware or account.

## Run, adapt, understand, or contribute

- [Start a project](start-here.md). The Start here guide takes you through firmware, setup, registration, and deployment. Build a complete program with a `while True` loop you own, then make an edit, redeploy, and observe the change.
- [Choose an example](examples.md). Select a complete existing program from the catalog. Change a period, response, or component, then observe the result.
- [Understand cooperative multitasking](cooperative-multitasking.md). Go directly to the explanation of generators, suspension and resumption, and loop ownership.
- Adopt or create a library. [Supply your own dependencies](contributing/standalone-integration.md) explains standalone integration with dependencies your project supplies. [Write a library](contributing/new-library.md) covers creating a component. Use [Tests and resource costs](quality-and-resource-costs.md) for tests and measured resource costs.
