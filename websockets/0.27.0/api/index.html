chumicro_websockets ¶

Non-blocking WebSocket client and server for CircuitPython, MicroPython, and CPython.

The public entry points are :class:WebSocketClient and :class:WebSocketServer.

from_config(config, on_connection, *, radio=None, listener=None, listener_factory=None, accept_path=None, max_connections=2, ticks=None, **constructor_kwargs) classmethod ¶

Build a :class:WebSocketServer from runtime config.

Config keys carry the deployment-varying values; any other constructor knob passes through verbatim as a keyword, and an explicit keyword wins over its config-derived value.

Construction is side-effect-free: with neither listener nor listener_factory given, a factory is built from the config's host / port and the bind happens on the first handle() tick.

io_interest(now_ms) ¶

Poll-interest bit for Runner.wait: read while the server is open with its listener bound and a connection slot free, else none.

next_deadline(now_ms) ¶

Earliest tick at which handle() must run.

The nearest connection deadline, capped at a short progress interval while any connection is live; connection sockets are not registered with the poller, so the cap keeps their I/O advancing.

close() ¶

Stop accepting new connections and close every active session.

check(now_ms) ¶

Return True if there's work to do this tick.

handle(now_ms) ¶

Lazy-open the listener, accept new connections, advance every active connection one tick.
